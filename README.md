# 2D-Shooting

A lightweight, Python-based **2D shooting game** framework designed to handle real-time rendering, movement mechanics, and FPS optimization.

## 🚀 Features
* **Smooth 2D Movement:** Responsive player controls.
* **Shooting Mechanics:** Real-time projectile handling.
* **FPS Counter:** Performance optimization script (`fps.py`) to monitor frame rates.

## 🛠️ Prerequisites
Make sure you have Python installed on your system. This project typically relies on the **Pygame** library of.

```bash
pip install pygame
```

## 🎮 How to Play
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd 2D-Shooting
   ```
3. **Run the game:**
   ```bash
   python fps.py
   ```

## 🕹️ Controls (Default)
* **W, A, S, D** or **Arrow Keys** — Move the player
* **Spacebar** or **Left Click** — Shoot projectiles
* **Esc** — Quit the game
